# SnipAgent 사용자 매뉴얼

SnipAgent는 Windows 시스템 트레이에서 동작하는 화면 캡처 도구입니다.
별도의 메인 창 없이 트레이 아이콘으로 조작하며, 캡처 결과를 PNG 파일이나
Windows 클립보드에 저장할 수 있습니다. Windows OCR 또는 OpenAI 호환 모델을
사용한 텍스트 추출과 AI 답변 기능도 제공합니다.

---

## 1. 시작하기

### 요구 사항

- Windows (Windows 전용 앱)
- .NET 10 데스크톱 런타임

### 실행

- 실행 파일을 실행하면 창이 뜨지 않고 **시스템 트레이(작업 표시줄 오른쪽 알림 영역)** 에
  SnipAgent 아이콘이 나타납니다.
- 앱은 한 번에 하나만 실행됩니다. 이미 실행 중일 때 실행 파일을 다시 실행하면 기존
  앱의 **Settings** 창이 열리고 새 인스턴스는 종료됩니다.
- Windows 시작 시 자동으로 실행되지 않으므로 필요할 때 직접 실행하세요.
- 트레이 아이콘이 보이지 않으면 작업 표시줄의 **∧ (숨겨진 아이콘 표시)** 버튼을
  눌러 확인하세요.

---

## 2. 기본 사용법

트레이 아이콘을 **마우스 오른쪽 버튼**으로 클릭하면 메뉴가 나타납니다.

| 메뉴 | 설명 |
|------|------|
| **Capture Region** | 드래그해서 선택한 영역을 캡처 |
| **Capture Full Screen** | 모니터 한 대의 전체 화면을 캡처 |
| **Settings** | 저장, 캡처, 텍스트 추출 및 AI 기능 설정 |
| **Exit** | 앱 종료 |

트레이 아이콘을 **두 번 클릭**해도 Settings 창이 열립니다.

캡처가 성공하면 완료 알림을 표시하지 않습니다. 단축키 충돌, 저장 실패, 텍스트 추출
실패처럼 사용자의 확인이 필요한 문제가 있을 때만 Windows 알림이 표시됩니다. OCR이나
AI 처리가 오래 걸리는 동안에는 **Saving…** 진행 창이 표시됩니다.

---

## 3. 영역 캡처 (Capture Region)

1. 트레이 메뉴에서 **Capture Region**을 선택하거나, 마지막 사용 모드가 영역 캡처인
   상태에서 전역 단축키를 누릅니다.
2. 캡처 지연이 설정되어 있으면 카운트다운이 먼저 표시됩니다.
3. 카운트다운이 끝난 순간의 전체 데스크톱이 고정되고, 모든 모니터에 어두운 선택
   오버레이가 나타납니다.
4. 캡처할 영역을 마우스로 드래그합니다.
5. 마우스 버튼을 떼거나, 영역을 만든 뒤 **Enter** 키를 눌러 확정합니다.
6. 취소하려면 **Esc** 키를 누릅니다.

> **마지막 영역 기억**: 직전에 캡처한 영역이 파란 박스로 미리 표시됩니다. 그대로
> **Enter**를 누르면 같은 영역을 다시 캡처할 수 있습니다. 새로 드래그하면 기억할
> 영역도 바뀝니다.

> 아주 작은 드래그는 실수로 간주됩니다. 캡처를 확정하지 않고 오버레이를 유지하므로
> 다시 선택할 수 있습니다.

---

## 4. 전체 화면 캡처 (Capture Full Screen)

- **모니터가 한 대**이면 선택 화면 없이 해당 모니터 전체를 캡처합니다.
- **모니터가 여러 대**이면 각 모니터에 번호가 표시된 선택 오버레이가 나타납니다.
  - 캡처할 모니터를 마우스로 클릭하거나,
  - 해당 **번호 키(1~9 또는 숫자 키패드 1~9)** 를 누릅니다.
  - **Esc** 키를 누르면 취소됩니다.

캡처 지연이 설정된 경우에는 모니터 선택 화면보다 먼저 카운트다운이 표시되며,
카운트다운이 끝난 순간의 화면이 캡처 대상으로 고정됩니다.

> **마지막 모니터 기억**: 직전에 캡처한 모니터가 금색 테두리와 `(last)` 표시로
> 강조됩니다. **Enter** 키를 누르면 그 모니터를 다시 캡처할 수 있습니다.

---

## 5. 전역 단축키 (Global Hotkey)

- 기본 단축키는 **Ctrl + Alt + S** 입니다.
- 단축키는 마지막으로 사용한 캡처 모드(영역 또는 전체 화면)를 반복합니다.
- 다른 앱을 사용 중일 때도 동작하는 Windows 전역 단축키입니다.
- 캡처가 진행 중일 때 중복으로 누른 단축키나 캡처 요청은 무시됩니다.

단축키로 캡처를 시작하면 직전에 캡처한 영역 또는 모니터가 미리 선택됩니다.
**Enter**를 누르면 같은 대상을 다시 캡처하고, 새 영역을 드래그하거나 다른 모니터를
선택할 수도 있습니다.

---

## 6. 설정 (Settings)

Settings 창 아래의 **Save**를 누르면 변경 사항을 저장하고, **Cancel**을 누르면
이번에 변경한 내용을 적용하지 않고 닫습니다.

### 6.1 Save Option

#### Save folder

- PNG 스크린샷을 저장할 폴더입니다.
- **Browse…** 버튼으로 폴더를 선택할 수 있습니다.
- 기본 폴더는 `내 사진(Pictures)\SnipAgent`입니다.
- 지정한 폴더가 삭제되었거나 접근할 수 없으면 자동으로 기본 폴더에 저장하고
  Windows 알림으로 실제 저장 위치를 알려 줍니다.
- 저장 방식에서 파일 저장을 사용하지 않으면 이 설정은 캡처 결과에 영향을 주지
  않습니다.

#### File name pattern

- PNG 확장자 `.png`는 자동으로 붙습니다.
- 기본 패턴은 `Screenshot_{datetime}`입니다.
- 설정 창의 **Preview**에서 생성될 파일 이름을 확인할 수 있습니다.

| 토큰 | 의미 | 예시 |
|------|------|------|
| `{datetime}` | 날짜_시각 (`yyyyMMdd_HHmmss`) | `20260911_190125` |
| `{date}` | 날짜 (`yyyyMMdd`) | `20260911` |
| `{time}` | 시각 (`HHmmss`) | `190125` |

`settings.json`을 직접 편집하는 경우 `{timestamp}`도 `{datetime}`과 동일하게
처리됩니다. 알 수 없는 토큰은 그대로 남습니다.

- Windows 파일 이름에 사용할 수 없는 문자는 `_`로 치환됩니다.
- 같은 이름의 파일이 이미 있으면 `_001`, `_002` 순으로 번호가 붙습니다.
- 텍스트 추출 파일은 PNG와 같은 기본 이름을 사용합니다.

### 6.2 Capture Options

#### Global hotkey

- 입력란을 클릭한 뒤 원하는 키 조합을 누릅니다.
- **Ctrl, Alt, Shift, Win 중 하나 이상**을 반드시 포함해야 합니다.
- Windows나 다른 앱이 이미 사용 중인 조합은 등록할 수 없습니다.
- **Save**를 누르면 새 단축키가 즉시 등록됩니다.

#### Capture delay

다음 값 중 하나를 선택할 수 있습니다.

| 설정 | 동작 |
|------|------|
| **Off** | 즉시 캡처 화면 고정 |
| **3 seconds** | 3초 카운트다운 후 화면 고정 |
| **5 seconds** | 5초 카운트다운 후 화면 고정 |
| **10 seconds** | 10초 카운트다운 후 화면 고정 |

카운트다운 중 메뉴를 열거나 툴팁에 마우스를 올려 원하는 화면 상태를 만들 수 있습니다.
영역 및 전체 화면 캡처 모두에 적용되며, 카운트다운 자체는 결과에 포함되지 않습니다.

#### Saving option

텍스트 추출 방식과 별개로 결과를 어디에 보낼지 선택합니다.

| 설정 | 파일 | 클립보드 |
|------|------|----------|
| **Save to file** | PNG와 추출 텍스트 저장 | 저장 안 함 |
| **Save to clipboard** | 저장 안 함 | 이미지 또는 추출 텍스트 복사 |
| **Save to file and clipboard** | 파일 저장 | 클립보드에도 복사 |
| **Off** | 저장 안 함 | 복사 안 함 |

- 텍스트 추출이 **None**이면 클립보드에는 캡처 이미지가 복사됩니다.
- 텍스트 추출이 켜져 있으면 클립보드에는 이미지 대신 추출된 텍스트가 복사됩니다.
- 추출 결과가 비어 있으면 클립보드에는 아무것도 복사하지 않고 알림을 표시합니다.
- **Off**에서도 `Use AI Skills`의 답변 오버레이는 표시되지만 결과는 저장되지 않습니다.

### 6.3 Advanced Options > AI Capture

상단 목록에서 캡처 후 실행할 텍스트 추출 방식을 선택합니다.

| 선택 항목 | 동작 | 파일 저장 시 추가 결과 |
|-----------|------|------------------------|
| **None** | 텍스트를 추출하지 않음 | PNG만 저장 |
| **Extract text (Windows OCR)** | Windows 내장 OCR로 일반 텍스트 추출 | 같은 이름의 `.txt` 파일 |
| **Extract text (Using LLM)** | OpenAI 호환 모델로 구조화된 Markdown 추출 | 같은 이름의 `.md` 파일 |
| **Use AI Skills** | 선택한 AI Skill을 캡처에 실행하고 답변 표시 | 추출 내용과 답변을 합친 `.md` 파일 |

예를 들어 Windows OCR을 사용하면
`Screenshot_20260911_190125.png`와 `Screenshot_20260911_190125.txt`가 생성됩니다.
LLM 기반 방식을 사용하면 텍스트 파일 확장자는 `.md`입니다.

#### Windows OCR

- Windows 사용자 언어 중 OCR 언어 팩이 설치된 언어를 사용합니다.
- 언어 팩이 없거나 이미지에서 텍스트를 찾지 못하면 텍스트 파일은 생성되지 않습니다.
- OCR 실패가 PNG 저장을 막지는 않습니다.

#### AI Skills 관리

`Use AI Skills`를 선택하면 AI Skills 영역이 활성화됩니다.

- 목록에서 Skill을 선택하면 아래에서 프롬프트를 미리 볼 수 있습니다.
- 연필 버튼으로 선택한 Skill을 편집합니다.
- `+` 버튼으로 새 Skill을 추가합니다.
- 휴지통 버튼으로 선택한 Skill을 삭제합니다.
- **Restore defaults**는 추가한 Skill과 기본 Skill에 대한 편집을 모두 버리고 내장
  기본 목록으로 되돌립니다. 확인 대화 상자에서 승인해야 적용됩니다.

Skill 추가/편집 창에서는 다음을 설정할 수 있습니다.

- **Skills Name**: 중복되지 않는 Skill 이름
- **Skills Prompt**: 캡처 이미지에 적용할 질문 또는 지시문
- **Use web search tool**: 모델의 호스팅 웹 검색 도구 사용
- **MCP server**: 사용할 원격 MCP 서버 목록

MCP 서버는 절대 주소 형식의 `http://` 또는 `https://` 엔드포인트만 지원합니다.
각 서버 왼쪽의 체크박스로 사용 여부를 정하고, `+`로 행을 추가하거나 `×`로
삭제할 수 있습니다.

### 6.4 Advanced Options > AI Settings

LLM 기반 추출이나 AI Skills를 사용하려면 다음 항목을 설정합니다.

- **Base URL**: OpenAI 호환 엔드포인트 주소
  - 기본값: `https://api.openai.com/v1`
- **Model**: 사용할 모델 또는 배포 이름
  - 기본값: `gpt-5.6-sol`
- **API Key**: 엔드포인트 인증 키

API 키는 일반 텍스트 `settings.json`이 아니라 **Windows 자격 증명 관리자
(Credential Manager)** 에 저장됩니다. 키가 이미 저장되어 있으면 API Key 입력란을
비워 둔 채 저장해도 기존 키가 유지됩니다. 새 값을 입력하면 기존 키를 교체합니다.

## 7. AI 답변 오버레이 사용법

`Use AI Skills`를 선택한 상태에서 캡처하면 선택 영역 또는 모니터 중앙에 항상 위에
표시되는 답변 오버레이가 열립니다.

1. 상단 **AI Skill** 목록에서 실행할 Skill을 선택합니다.
2. **Enter**를 눌러 실행합니다.
3. 실행 중에는 `Running...` 상태가 표시됩니다.
4. 답변이 나타나면 내용을 확인하고 **Enter** 또는 **Esc**를 눌러 닫습니다.

- 실행 전에 **Esc**를 누르면 요청하지 않고 닫습니다.
- 실행 중 **Esc**를 누르면 진행 중인 요청을 취소하고 닫습니다.
- 오른쪽 위 닫기 버튼을 선택하면 오버레이가 닫힙니다. 요청 실행 중에는
  **Esc**와 동일하게 요청을 취소한 후 닫습니다.
- 마지막으로 실행한 Skill은 기억되어 다음 오버레이에서 미리 선택됩니다.
- `AI answer` 제목을 마우스로 드래그하면 오버레이를 옮길 수 있습니다.
- 오버레이의 가장자리나 모서리를 드래그하면 크기를 조절할 수 있습니다. 최소
  크기는 480 x 320이며, 마지막 크기는 다음 캡처에 적용됩니다. 새 오버레이는
  캡처 영역 중앙에 열리고 이전 화면 위치는 기억하지 않습니다.
- 왼쪽 아래 **Opacity** 슬라이더로 배경 투명도를 20%~100% 범위에서 조절할 수
  있습니다. 슬라이더에 포커스를 둔 뒤 방향키로도 조절할 수 있습니다.
- 마지막 크기와 투명도는 `settings.json`에 저장되어 다음 실행에 적용됩니다.
  이 값들은 Settings 창에서는 변경할 수 없습니다.

파일 저장이 활성화되어 있으면 AI Skills 결과의 `.md` 파일에는 캡처에서 추출한
Markdown과 Skill 답변이 각각 `Extracted text`, `Answer` 제목 아래에 함께 저장됩니다.

---

## 8. 설정 파일

일반 설정은 다음 위치에 JSON 형식으로 저장됩니다.

```text
%AppData%\SnipAgent\settings.json
```

API 키는 이 파일에 포함되지 않고 Windows 자격 증명 관리자에 별도로 저장됩니다.
설정 파일을 직접 편집하기보다 Settings 창을 사용하는 것을 권장합니다.

## 9. 문제 해결

| 증상 | 원인 / 해결 |
|------|-------------|
| 단축키가 동작하지 않음 | Windows나 다른 앱이 같은 조합을 사용 중일 수 있습니다. Settings에서 다른 단축키를 선택하세요. |
| 저장 폴더 관련 알림이 표시됨 | 지정한 폴더를 사용할 수 없어 `Pictures\SnipAgent`에 대신 저장된 것입니다. 유효한 폴더로 변경하세요. |
| 트레이 아이콘이 보이지 않음 | 숨겨진 아이콘 영역을 확인하세요. Windows 탐색기가 재시작되면 아이콘은 자동으로 복구됩니다. |
| 화면 일부가 검게 캡처됨 | UAC 보안 데스크톱이나 DRM 보호 영상은 캡처할 수 없습니다. |
| OCR을 켰는데 `.txt` 파일이 생성되지 않음 | 텍스트가 없거나 필요한 OCR 언어 팩이 설치되지 않았을 수 있습니다. Windows 설정의 **언어 및 지역**에서 언어 기능을 확인하세요. |
| AI 기능에서 인증 또는 요청 오류가 발생함 | Base URL, Model, API Key를 확인하고 해당 모델이 이미지 입력을 지원하는지 확인하세요. |
| AI Skills 목록이 비어 있음 | Settings에서 Skill을 추가하거나 **Restore defaults**로 내장 목록을 복원하세요. |
| 클립보드에 아무것도 복사되지 않음 | 텍스트 추출이 켜진 상태에서 추출 결과가 비어 있으면 복사하지 않습니다. 필요하면 추출 방식을 **None**으로 바꾸어 이미지를 복사하세요. |

## 10. 제한 사항

- Windows 시작 시 자동 실행 기능은 없습니다.
- 캡처 성공 완료 알림은 제공하지 않습니다.
- PNG 이외의 이미지 파일 형식은 지원하지 않습니다.
- UAC 보안 데스크톱과 DRM 보호 콘텐츠는 캡처할 수 없습니다.
- 여러 모니터 환경에서는 모니터별 배율과 가상 데스크톱 좌표를 처리하지만, Windows가
  캡처를 차단하는 콘텐츠는 저장할 수 없습니다.
- LLM 및 AI Skills 기능은 설정한 외부 OpenAI 호환 엔드포인트의 기능, 모델,
  네트워크 상태 및 사용 정책에 영향을 받습니다.
